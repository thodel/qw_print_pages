# qw_print_pages

Website zu [qw_print](https://github.com/thodel/qw_print): Neulesung des Quellenwerks zur Entstehung der
Schweizerischen Eidgenossenschaft, in Absprache mit der Schweizerischen Gesellschaft für Geschichte (SGG).
Erzeugt von `python -m qw_print.site` aus `qw_print.export` (P7, erste Fassung 27.11.2026: Bände, Seitenblätterer
mit Kursiven und Zeilenzahlen, Volltextsuche). Online: https://thodel.github.io/qw_print_pages/ (gestellt von Tobias Hodel, Mitglied des SGG-Vorstands).
